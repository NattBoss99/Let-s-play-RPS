Rock Paper Scissors — เกมเป่ายิ้งฉุบ
ทำด้วย HTML, CSS, JavaScript และใช้ Bootstrap 5 ในการจัด layout

คุณสมบัติ
-เล่นกับคอมพิวเตอร์แบบ real-time
-แสดงผลรอบต่อรอบ พร้อม flash animation
-เก็บคะแนนผู้เล่นและคอมพิวเตอร์
-มีปุ่มรีเซ็ตเกม เพื่อเริ่มใหม่
-เปลี่ยนโหมดเกมได้ (First to 3/5/7)
-รองรับการแสดงผลบนมือถือด้วย responsive design

วิธีใช้งาน
-https://nattboss99.github.io/Let-s-play-RPS/ หรือ
-ดาวน์โหลดไฟล์ทั้งหมด: index.html, style.css, script.js
-เปิดไฟล์ index.html ในเว็บเบราว์เซอร์ (Chrome, Edge, Firefox ฯลฯ) หรือใช้ Live Server จาก VS Code เพื่อรันทดสอบ
-เลือก ค้อน ✊ / กระดาษ ✋ / กรรไกร ✌️ เพื่อเริ่มเล่น
-ดูผลคะแนนและผลลัพธ์รอบต่อรอบ
-กดปุ่มรีเซ็ตหรือเปลี่ยนโหมด เพื่อเล่นต่อหรือปรับความยากขึ้น

ขั้นตอนการทำ project

HTML
1 สร้างโครง html เพิ่ม Bootstrap และเชื่อม CSS + JS
2 ทำ Layout เกม
3 ทำ Scoreboard
4 สร้างปุ่มเลือก
5 สร้างกล่องผลลัพธ์
6 ปุ่มควบคุม
JS
1 สร้าง emoji map แล้วดึง DOM
2 สร้างตัวแปรเก็บ state คะแนนของเกม
3 สุ่มการเลือกของคอม
4 ตัดสินผู้ชนะ ใช้ object map แทนเพื่อแมปว่าผู้เล่นเลือกแต่ละตัวเลือกแล้วจะชนะอะไร (ไม่ใช้if+returnหลายเงื่อนไข เพราะเกิด complexity is 11 you must be kidding)
5 อัปเดตคะแนน
6 แสดงผลรอบ และเพื่อเช็คว่าเกมจบไหม
7 Animation ชนะ
8 ทำฟังก์ชั่น endGame() เพื่อจบเกม resetGame() เพื่อรีเช็ทเกม และ changeMode() เพื่อเปลี่ยนโหมดเกม
9 เมื่อผู้เล่นกดปุ่มให้ฟังก์ชั่น onPlayerChoice() ทำงาน
10 ผูก Event
11 เริ่มเกมตอนเปิดเว็บด้วย resetGame(); ตอนเปิดหน้าเว็บครั้งแรก → เรียก resetGame() เพื่อให้คะแนนเป็น 0-0 และข้อความเริ่มต้นแสดง
CSS
1 เริ่มจาก CSS Variables (root) เปลี่ยนสีทีเดียวทั้งเว็บ
2 background หน้าเว็บ
3 ตกแต่ง Card ให้ดูเหมือนเกม
4 ทำปุ่มให้ดูเป็นเกม
5 ทำ Animation
